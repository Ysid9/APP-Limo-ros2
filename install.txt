======================================================
  APP-Limo_ros2_3in — Instructions d'installation
======================================================

Deux modes d'utilisation :
  - Windows  → CoppeliaSim  → torch_run.py
  - Ubuntu   → ROS2 + Gazebo → torch_run_ros2.py

Les fichiers d'apprentissage (torch_back.py, torch_online.py,
monitoring.py, data_logger.py) sont communs aux deux.


======================================================
  WINDOWS — CoppeliaSim
======================================================

1. Installer Python 3.10+
   https://www.python.org/downloads/windows/
   ⚠ Cocher "Add Python to PATH" lors de l'installation.

   Vérifier dans PowerShell :
     python --version

2. Installer les dépendances Python
   Dans PowerShell :
     python -m pip install --upgrade pip
     pip install torch matplotlib PyQt5 pyzmq cbor2 coppeliasim-zmqremoteapi-client

3. Installer CoppeliaSim
   https://www.coppeliarobotics.com/downloads
   Télécharger la version Windows et décompresser, par exemple dans C:\CoppeliaSim.

4. Lancer la simulation
   a. Ouvrir CoppeliaSim
   b. File > Open Scene > sélectionner le fichier simu.ttt du projet
   c. Cliquer Play (▶) pour démarrer la simulation
   d. Vérifier dans la console CoppeliaSim :
        [ZMQ remote API server@addOnScript] ZeroMQ Remote API server starting (rpcPort=23000)...

5. Lancer le script dans PowerShell
     cd C:\chemin\vers\APP-Limo_ros2_3in
     python torch_run.py

   Répondre aux prompts :
     - Enable real-time display? → y pour afficher le monitoring, n sinon
     - Do you want to load previous network? → y pour charger last_w_torch_3in.json
     - Do you want to learn? → y pour activer le backprop, n pour évaluation seule
     - Enter the first target : x y radian → 0 0 0

   Le robot Pioneer apparaît dans CoppeliaSim et converge vers la cible.
   Si le monitoring est activé, les graphes sont sauvegardés en fin de session.


======================================================
  UBUNTU 22.04 — ROS2 Humble + Gazebo
======================================================

1. Installer ROS2 Humble

   sudo apt install software-properties-common curl

   sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
     -o /usr/share/keyrings/ros-archive-keyring.gpg

   echo "deb [arch=$(dpkg --print-architecture) \
     signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
     http://packages.ros.org/ros2/ubuntu $(lsb_release -cs) main" \
     | sudo tee /etc/apt/sources.list.d/ros2.list

   sudo apt update

   sudo apt install \
     ros-humble-desktop \
     ros-humble-gazebo-ros-pkgs \
     ros-humble-joint-state-publisher-gui \
     python3-colcon-common-extensions

2. Installer les dépendances Python
     pip install torch matplotlib PyQt5

3. Créer le workspace ROS2 et y placer le modèle Limo

     mkdir -p ~/ros2_ws/src
     cp -r /chemin/vers/APP-Limo_ros2_3in/limo_ros2 ~/ros2_ws/src/

   Compiler :
     cd ~/ros2_ws
     source /opt/ros/humble/setup.bash
     colcon build

   Ajouter au ~/.bashrc pour ne pas avoir à sourcer à chaque fois :
     echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
     echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
     source ~/.bashrc

4. Lancer Gazebo (Terminal 1)
     ros2 launch limo_description gazebo_models_diff.launch.py

   Le robot Limo apparaît à la position (0, 0, 0) dans Gazebo.
   Deplacer le robot à la position initiale voulu.

5. Lancer le script (Terminal 2)
     cd /chemin/vers/APP-Limo_ros2_3in
     python3 torch_run_ros2.py

   Répondre aux prompts :
     - Real robot? → n (simulation Gazebo) (y pour robot limo réel)
     - Enable real-time display? → y pour le monitoring, n sinon
     - Do you want to load previous network? → y pour charger last_w_torch_3in.json
     - Do you want to learn? → y pour activer le backprop, n pour évaluation seule
     - Enter the first target : x y radian → 0 0 0 (toujours)

   Le robot converge vers la cible.
   Appuyer sur Entrée pour stopper la session.
   Entre chaque session, déplacer le robot manuellement dans Gazebo.
   À la fin, les résultats sont dans res/gazebo/run_YYYYMMDD_HHMMSS/.

6. Visualiser les résultats .csv enregistrés si graphe manquants
     python3 plot_results.py
   (cherche automatiquement dans res/ et génère les graphes manquants)


======================================================
  PARAMETRES MODIFIABLES (torch_run_ros2.py)
======================================================

  HL_size      = 1000   # taille de la couche cachée du réseau
  LEARNING_RATE = 0.2   # pas d'apprentissage


======================================================
  NOTES
======================================================

- Le fichier last_w_torch_3in.json contient les poids sauvegardés
  de la dernière session d'entraînement. Supprimer ce fichier pour
  repartir de zéro avec des poids aléatoires.

- ROS2 et Gazebo ne fonctionnent pas nativement sur Windows.
  Sur Windows, utiliser uniquement CoppeliaSim (torch_run.py).
