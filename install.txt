Instructions d'installation — coppelia_pioneer (Windows, CoppeliaSim)

Fichiers du projet :
  torch_run.py               -- script principal
  torch_back.py              -- réseau de neurones PioneerNN
  torch_online.py            -- boucle d'apprentissage en ligne
  zmq_pioneer_simulation.py  -- interface CoppeliaSim via ZMQ
  data_logger.py             -- enregistrement CSV et graphiques
  monitoring.py              -- affichage temps réel (optionnel)
  simu.ttt                   -- scène CoppeliaSim


1. Installer Python 3.8+

   Téléchargez Python (>= 3.8) depuis https://www.python.org/downloads/windows/
   Cochez "Add Python to PATH" lors de l'installation.

   Vérification dans PowerShell :
     python --version


2. Installer les dépendances Python

   Dans PowerShell :
     python -m pip install --upgrade pip
     pip install torch matplotlib PyQt5 pyzmq cbor2 coppeliasim-zmqremoteapi-client

     torch                            : PyTorch
     matplotlib + PyQt5               : graphiques et affichage temps réel
     pyzmq + cbor2                    : dépendances ZMQ Remote API
     coppeliasim-zmqremoteapi-client  : client Python pour CoppeliaSim


3. Installer CoppeliaSim (Windows)

   Téléchargez depuis https://www.coppeliarobotics.com/downloads
   Décompressez dans C:\CoppeliaSim (ou autre emplacement).

   Au démarrage de CoppeliaSim, vérifiez dans la console :
     [ZMQ remote API server@addOnScript] ZeroMQ Remote API server starting (rpcPort=23000)...


4. Préparer le projet

   Copiez le dossier du projet dans un emplacement Windows, par exemple :
     C:\Users\VotreNom\Documents\coppelia_pioneer


5. Lancer

   a. Ouvrez CoppeliaSim, chargez simu.ttt (File > Open Scene), cliquez Play (▶).

   b. Dans PowerShell :
        cd C:\Users\VotreNom\Documents\coppelia_pioneer
        python torch_run.py

   c. Répondez aux prompts :
        Enable real-time display?             --> y (monitoring) ou n
        Do you want to load previous network? --> y (charge last_w_torch_3in.json) ou n
        Do you want to learn?                 --> y (apprentissage) ou n
        Enter the first target : x y radian  --> ex: 0 0 0


6. Résultats

   Les résultats sont sauvegardés dans res/run_YYYYMMDD_HHMMSS/ :
     training_session_N_*.csv / .png   -- données de chaque session
     run_total.csv / .png              -- toutes sessions combinées
     run_trajectoires.png              -- trajectoires XY par session (couleurs)

   Les poids entraînés sont sauvegardés dans last_w_torch_3in.json
   (le script demande confirmation avant d'écraser le fichier existant).


Paramètres modifiables (torch_run.py) :
  HL_size       = 1000   -- taille de la couche cachée
  LEARNING_RATE = 0.2    -- taux d'apprentissage
